# PBZ-Online

影之刃零（ProjectPBZ）房间制 PvP Mod 的前期调查与网络设计。

**当前尚无可安装的联机 Mod，未验证玩家互伤，也没有运行中的中继服务。** 首版归档已有证据、实现入口和后续步骤，避免把函数名或引擎通用功能当作游戏已经支持 PvP 的证明。

## 目标

- 玩家互相对战，房主选择竞技场与统一角色配置。
- 左上角显示每位玩家的血量、死亡与连接状态。
- 同一对局协议支持客户端直连房主和全部玩家经服务器中继。
- 中继不启动游戏；房主仍运行游戏及权威战斗判定。
- 保留个人存档，对局使用隔离的临时状态。

## 重要边界

中继可减少房主重复上传同一快照的负担，也可能改善路由；**无法让房主游戏线程停顿或房主断网时继续正常出具权威战斗结果**。真正解除这一依赖需要独立判定服务或经过验证的判定权迁移。

本仓库不包含游戏文件、解密密钥、个人存档、游戏反编译全文、REA/Ghidra 工具包。记录的地址仅对应调查版本，更新后必须重新定位。
